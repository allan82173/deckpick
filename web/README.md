# DeckPick app

실행: `npm.cmd run dev` → http://localhost:3100

검증: `npm.cmd run typecheck`, `npm.cmd test`, `npm.cmd run build`.

전체 초안의 페이지 사이에서 키메시지·질문 한 문장으로 새 장을 추가할 수 있습니다. 기존 장표는 보존하며 최대 30장까지 지원합니다. 상세 기준은 상위 `docs/중간페이지-추가.md`를 참고하세요.

전체 초안 왼쪽의 세로 미리보기 목록에서 장별 이동과 현재 위치 확인을 지원합니다. 기준은 상위 `docs/전체초안-페이지탐색.md`를 참고하세요.

전체 초안의 텍스트·도형·이미지를 누르면 화면에서 직접 편집할 수 있습니다. 저장과 PPTX에도 반영하며 상세 범위는 상위 `docs/장표-화면직접편집.md`를 참고하세요.

장표 오른쪽 위의 후보 보기 버튼 아래에서 A·B·C를 비교하고 바로 적용합니다. 기준은 상위 `docs/장표-오른쪽후보패널.md`를 참고하세요.

페이지 추가 버튼은 구분선 사이의 작은 A안으로 적용했습니다. 상단 탐색과 블록 정렬 기준은 상위 `docs/목차-블록정렬-개선.md`를 참고하세요.

장표 아래의 장별 AI 대화는 전체 덱의 최신 요약과 최근 요청을 공유하고 해당 장만 수정합니다. 직접 편집은 즉시 저장하며 이동·크기 손잡이, 한 줄 표지 우선, 새 페이지 근거 파일 첨부를 지원합니다. 상위 `docs/장별대화-편집저장-개선.md`에 검증 범위를 기록했습니다.

전체 안내는 상위 `README.md`, 스타일 분석과 검증 기록은 상위 `docs/`를 참고하세요. 2026-10-30 사용자 요청으로 API 없는 공개 데모를 https://deckpick.vercel.app 에 배포했습니다. 배포 범위·검증은 상위 docs/Vercel-공개데모-배포.md를 참고하세요.

앱 코드와 테스트는 TypeScript입니다. `src/lib/scene.ts`의 좌표와 텍스트 구획을 미리보기와 PPTX 출력이 공유합니다. API 키는 덱 데이터와 별도로 sessionStorage 또는 서버 `.env.local`에 둡니다. 사용자 원본 PPT·PDF와 분석 자료는 이 앱 폴더에 포함하지 않습니다.

현재 공개 버전은 소개 + 단일 가상 사례의 읽기 전용 단계별 예시입니다. /example/input·outline·draft에서 자료대화/목차/전체초안을 볼 수 있으며 공개 생성·편집·첨부·다운로드는 비활성화했습니다. 로컬 앱은 그대로 사용합니다.
