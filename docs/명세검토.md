# DeckPick 명세 이해와 구현 전 확인사항

검토일: 2026-10-28. 사용자 제공 deckpick-spec.md 전체와 공개 목업의 1~3단계 화면을 확인했습니다. 최종 화면·다운로드 요구는 명세에서 확인했으며 실제 PPTX 다운로드 동작을 검증한 것은 아닙니다.

## 사용자가 고르는 지점을 중심으로 한 흐름

- 화면 1: 덱 유형과 스타일·기본 정보, BYOK 연결, 대화 중 아웃라인·키메시지 제안. 제안의 과거 버전을 보존합니다.
- 화면 2: 아웃라인 수정·순서 조정·추가·확인 후 삭제. AI 제안은 사용자의 반영 버튼을 거쳐 적용합니다.
- 화면 3: 170px 슬라이드 목록, 가운데 후보·직접 수정, 320px AI 채팅. 색 변경과 편집 결과를 즉시 반영합니다. 직접 편집한 내용이 있으면 재생성 전 확인합니다. 후보는 슬라이드별 순차 생성합니다.
- 화면 4: 선택·수정된 슬라이드와 출처, 편집 가능한 PPTX 다운로드, 발표자 노트의 출처, 폰트 설치 안내, 데모 피드백 질문.

## 빠뜨리면 안 되는 기술 기준

- Next.js App Router / TypeScript / Tailwind / zod / pptxgenjs. OpenAI·Anthropic 모델명은 설정값입니다.
- DesignSystem의 11개 색상 토큰과 DeckType의 아웃라인·문체는 별개입니다. 기본 ict-forest는 지정된 고정 hex를 사용하며, 사용자 주색은 별도 HSL 파생 규칙을 적용합니다.
- 컨설팅 8개, 마케팅 6개 레이아웃은 각각 data 스키마와 Preview·toPptx를 갖습니다. 좌표(in) 상수와 데이터를 공유하며 HTML을 이미지로 변환하는 방식은 사용하지 않습니다.
- 키를 제외한 진행 상태만 localStorage에 보관합니다. BYOK는 sessionStorage → x-user-api-key → 자기 서버 → 해당 제공자 순서이며 로그와 덱 데이터에 포함하지 않습니다.
- LLM 구조화 응답을 zod로 검증하고 최대 2회 재시도합니다. 후보 ID 중복·텍스트 길이·출처의 research 포함 여부도 검증합니다. 웹 검색 결과에서 확인한 URL만 사용합니다.
- 실제 출처를 확인하지 못한 숫자나 통계는 확인 필요입니다. 목업의 12%, 20% 등의 가상 예시를 조사 결과로 재사용하지 않습니다.
- 컨설팅 본문은 40자 이하 결론형 헤드라인, 마케팅은 20자 이하 카피입니다. 글자 수 검사 외에도 실제 줄바꿈·박스 높이·PPTX 출력의 일치 검증이 필요합니다.

## 구현 전에 명확히 다룰 부분

1. `slideCount`는 데이터 모델에 5~12로 있으나 입력 화면의 컨트롤이 구체적으로 적혀 있지 않습니다. 구현 시 단순한 장수 선택을 제공하는 가정으로 기록할 수 있습니다.
2. `DeckInput.reference`는 타입 예시에는 있지만 뒤의 지침은 사용하지 않는다고 명시합니다. 채팅의 setup 기록을 기준으로 사용합니다.
3. 컨설팅 목차 레이아웃의 items는 3~5개입니다. 최대 12장 덱에서는 모든 장을 나열하는 대신 섹션 묶음과 어떻게 대응할지 설계해야 합니다.
4. 표지 외 후보의 레이아웃 3개가 달라야 합니다. 목차·결론에서도 의미를 유지하는 대체 레이아웃을 허용할지 실제 생성 규칙에 명시해야 합니다. 후보 수만 맞추려고 숫자나 근거를 만들지 않습니다.
5. 웹 검색과 구조화 출력의 결합 방식·지원 모델은 실제 제공자 공식 문서를 확인한 뒤 어댑터에서 처리합니다. API명이나 응답 구조를 목업에서 추정하지 않습니다.
6. 공유 SlideSpec과 좌표만으로 완전한 시각 일치를 보장하지는 않습니다. Pretendard 설치 여부·텍스트 측정·줄바꿈·텍스트 축소·삼각 화살표와 도형의 위치를 실제 출력으로 비교해야 합니다.
7. API 키 없는 데모는 데모로 명확히 표시합니다. 가짜 연결 성공·가짜 검색 출처를 실제 기능처럼 표시하지 않습니다.

이 메모는 명세를 축소하거나 요구를 바꾸는 승인이 아닙니다. 구현을 시작하면 명세의 단계별 수용 기준을 항목별로 추적하고, 미결정 사항은 가정 또는 확인 필요로 구분합니다.

## 확장 범위

기존 PPTX 업로드로 스타일 추출, 실제 이미지 검색, 덱 유형 추가, 선택 기록 기반 추천은 명세 13장의 후속 확장입니다. 최초 구현 완료 조건과 구분합니다.
