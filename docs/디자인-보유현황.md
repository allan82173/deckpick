# DeckPick 디자인 보유 현황

2026-10-30 코드의 layoutIds·dataSchemas·공통 장면과 테마를 기준으로 정리했다. 참고 자료를 읽었다는 사실을 실제 구현 완료와 혼동하지 않는다.

35개 등록 레이아웃 = 서로 다른 배치 유형 26개 + 컨설팅/마케팅 공용 구조의 중복 등록 9개다. 컨설팅 20개(표지·목차 포함), 마케팅 15개(표지 포함)다. 컨설팅 표지의 단색·사진 반반·화이트·큰 제목은 한 layout ID의 내부 변형이다. 색상은 고정 6개 + 사용자색이며 구조 개수에 곱하지 않는다.

| 용도 | 고유 배치 수 | 종류 |
|---|---:|---|
| 시작·전체 흐름 | 3 | 컨설팅 표지, 브랜드 표지, 독립 목차 |
| 병렬 설명·근거 | 3 | 병렬 박스, 특징 카드, 통찰+근거 |
| 문제·원인 | 3 | 원인 좁히기, 원인 트리, 문제·원인·검증 |
| 고객 경험 | 1 | 고객 여정 |
| 비교·선택 | 4 | 대안 비교표, 2×2 프레임, 포지셔닝 맵, 현재·제안 비교 |
| 시스템·연결 | 2 | 입력·연결·결과, 기존·제안 시스템 비교 |
| 실행·업무 과정 | 3 | 단계별 흐름, 실행 로드맵, 역할별 업무 흐름 |
| 숫자·변화 | 3 | 핵심 지표, 빅 넘버, 단일 계열 막대 추세 |
| 메시지·이미지·마무리 | 4 | 빅 메시지, 이미지&카피, 인용&행동 제안, 핵심 제언 |

현재 차트는 단일 계열 세로 막대이며, 이미지도 기본 표지·좌우 분할 수준이다. 추천되는 첫 확장 6종은 그룹 막대, 누적 막대, 선 그래프, 워터폴, 조사 근거+인사이트, 사진/화면+주석 사례다. 모두 신규 제안이며 구현 완료 목록에 넣지 않는다. 같은 유형 안에서 사진 비중·텍스트 밀도가 다른 시각적 변형도 부족하다.

추가 자료를 무조건 많이 받기보다 기존 PPT에서 각 목표 유형의 대표 장표 1~2장과 ‘좋은 이유’를 골라 설계로 옮기는 작업을 우선한다. 예: ‘제품 사진을 절반 사용’, ‘같은 기준의 3개 대안을 한 번에 비교’, ‘인터뷰 원문과 해석을 구분’. 6종×2장=12장의 참고면 첫 확장 범위를 정하는 데 유용하지만 정해진 최소 데이터 수는 아니다.

시각 지도: `web/output/screenshots/deckpick-design-map.png`. 이미지가 내장된 분류·검색 HTML: `web/output/deckpick-design-catalog.html`. 앱 로직·모델·테마는 이번 정리에서 변경하지 않았다. 이미지 렌더와 목록 35개 누락·중복 검사를 확인했으며 HTML의 검색 동작은 실제 브라우저에서 검증하지 않았다.
