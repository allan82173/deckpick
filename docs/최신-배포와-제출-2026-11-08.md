# 최신 버전 배포 및 제출 준비

기준 버전: Claude 작업 완료 커밋 2a3483c.

이번 보완은 결론 먼저 구성·가설과 검증·화면 정리·동시 실행 4개를 유지하면서 판단과 스토리라인의 HTTP 요청을 분리했다. 완료된 조사 결과와 판단을 보존해 스토리라인 재시도에서 조사를 반복하지 않는다. 변경된 입력이나 파일은 캐시 키로 구분한다.

클라우드에서는 단일 요청 예산 270초, 개별 제공자 호출 상한 260초를 적용한다. 로컬 story 대기는 330초를 유지한다. 실제 긴 유료 생성과 429 발생 여부는 이번 작업에서 측정하지 않았다.

테스트 212개·타입 검사·빌드 통과. API 키와 원본 첨부·개인 실행 기록을 배포 또는 GitHub 소스에 포함하지 않는다.

대표 주소: https://deckpick.vercel.app
저장소: https://github.com/allan82173/deckpick

둘 다 비공개이며 권한 있는 계정으로 로그인해야 한다. Vercel 자동 Git 연결은 계정의 GitHub Login Connection이 없어 거부됐다. 수동 배포는 가능하며 Root Directory는 web으로 준비했다. 계정 로그인 연결 후 vercel git connect로 자동 배포를 마칠 수 있다.
