# 전체 초안 페이지 탐색

전체 초안 왼쪽에 PPT처럼 세로 미리보기 목록을 둔다. 실제 선택·수정된 장표를 축소해서 보여주며 번호와 제목을 함께 표시한다. 미리보기를 클릭하면 해당 장으로 이동하고, 본문 스크롤에 맞춰 현재 페이지를 테두리와 `현재 / 전체` 표시로 알린다. 현재 장이 목록 밖으로 나가면 목록 자체도 따라 이동한다.

목록은 화면에 고정되며 별도로 스크롤할 수 있다. 좁은 화면에서는 제목을 숨기고 작은 미리보기와 번호를 유지한다. 페이지 추가 시 개수와 순서가 자동 반영된다. 이 기능은 덱 내용·선택·API 요청·PPTX 출력에 영향을 주지 않는다. 키보드 버튼 이동과 현재 페이지의 aria-current, 모션 축소 설정을 지원한다.

검증: TypeScript 검사 통과. 기존 6장 덱에서 네 번째 미리보기 클릭 후 해당 장 상단과 현재 표시가 4/6으로 맞는지, 본문 스크롤 후 5/6으로 갱신되는지 브라우저에서 확인했다. 유료 API 호출 없음. 화면 기록은 `web/output/screenshots/draft-page-navigator.png`다.

## 2026-10-30 왼쪽 목록에서 추가

각 미리보기 아래에 작은 녹색 테두리 ‘＋’ 버튼을 둔다. 선택한 장 바로 뒤의 기존 페이지 추가 입력창을 열고 해당 위치로 이동한다. 닫았다가 같은 버튼으로 다시 열 수 있다. 마지막 장의 버튼은 맨 뒤 추가를 연다. 생성 중·30장 제한에 도달하면 비활성화한다. 키보드와 보조기기에는 ‘N번 슬라이드 다음에 페이지 추가’로 위치를 알린다. 본문 A안 버튼과 같은 삽입 로직을 사용하며 중복 생성 코드를 만들지 않는다.

TypeScript 검사와 브라우저에서 중간 위치 열기·재열기·마지막 위치 열기·닫기를 확인했다. 검증 중 AI 생성은 요청하지 않았다. 화면: `web/output/screenshots/rail-page-add.png`.
