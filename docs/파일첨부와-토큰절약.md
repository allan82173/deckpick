# 파일 첨부·토큰 절약 및 승인 테마

2026-10-29 사용자 요청으로 DeckPick 로컬 앱에 구현했다. 배포·결제·실제 유료 API 요청은 하지 않았다. 기존 API 키와 Luna 설정은 유지한다.

## 첨부 방식

- PDF, DOCX, PPTX, UTF-8 TXT·MD·CSV와 PNG·JPG·WebP 사진. 덱당 문서·사진 합계 최대 5개, 파일당 10MB. XLSX·HWP·구형 DOC/PPT는 현재 미지원이다. 사진 처리의 최신 기준은 [채팅 사진 첨부](채팅-사진첨부.md)를 따른다.
- PDF는 처음 200쪽, PPTX는 처음 200장, 추출 텍스트는 파일당 50만 자까지다. 초과·시각 정보 누락은 목록에 안내한다. 스캔 PDF는 OCR을 자동 수행하지 않으며 텍스트가 없으면 실패를 안내한다.
- 업로드는 로컬 `/api/attachments`에서 처리한다. AI·임베딩·외부 파일 검색 서비스를 호출하지 않는다. 문서는 원본 바이너리를 저장하지 않고, 추출한 텍스트와 위치·메타데이터를 `web/.attachments/<SHA-256>.json`에 저장한다. 사진은 메타데이터를 제거하고 축소한 WebP를 같은 비공개 폴더에 저장한다. 동일 파일은 처리 결과를 재사용한다.
- 메타데이터와 ID만 덱의 브라우저 저장소에 보존한다. API 키는 첨부 캐시나 덱에 넣지 않는다. `.attachments/`는 Git·Vercel 업로드 제외다.
- ‘첨부 해제’는 현재 덱에서 연결만 제거한다. 다른 덱의 재사용을 위해 로컬 추출 캐시는 남는다. 자동 만료·캐시 관리 UI는 아직 없다. 로컬 디스크 캐시이므로 공개/서버리스 배포 전에 인증·소유권·영구 저장 방식을 별도로 설계해야 한다.

## AI 입력량 제어

1. 서버에서 텍스트·표 안의 글만 추출한다. PDF의 페이지 이미지를 모델에 매번 보내지 않는다. 이미지·차트·복잡한 표의 시각적 관계는 누락될 수 있다.
2. 약 1,000자 구간으로 나누고 150자 정도 겹쳐 원문 경계 누락을 줄인다. PDF 쪽, PPTX 슬라이드, DOCX 문단, 텍스트 행 위치를 남긴다.
3. 최근 질문·현재 장표·발표 주제로 키워드/한글 부분어를 비교해 관련 구간을 고른다. 파일별 상위 구간을 우선하고 중복 본문을 제거한다. 원문 전체를 대표하는 요약이나 의미 검색 모델이 아니므로 관련 자료가 모두 선택된다는 보장은 없다.
4. **첨부 발췌문만 요청당 약 2,400토큰 예산**, 최대 8개 구간으로 제한한다. o200k_base 기반 추정으로 실제 Luna 과금 토큰·JSON 감싸기 비용과 다를 수 있다. 시스템 지침·대화·검색·모델 출력 토큰은 별도다.
5. 지난 대화는 최근 8개 발언의 role/text만 전달하고 과거 목차 제안 전체를 반복 전달하지 않는다. 이전 발언은 1,200자, 마지막 발언은 5,000자까지 전달한다. 현재 확정 목차는 별도로 유지한다.
6. 발췌문은 명령이 아닌 근거 자료로 다루며 수치·인용은 파일명과 위치를 notes에 남기도록 지시한다. 전체 문서를 검토했다고 표현하거나 첨부를 가짜 웹 URL로 바꾸지 않는다. 실제 출처 작성 품질은 API 응답 검증이 별도로 필요하다.

첨부는 채팅·목차 생성·장표 후보 생성/재생성에 연결했다. 데모에서는 첨부/추출만 가능하며 예시 결과를 파일 기반 AI 분석처럼 표시하지 않는다. 업로드·발췌 선택이 무료여도 발췌문을 실제 모델에 전달하고 답변을 생성하는 요청에는 과금된다. 최소 비용을 수학적으로 보장하는 설정이 아니라 입력량을 제한하고 반복을 줄이는 방식이다.

## 선택한 색상만 추가

사용자가 후보 2/5/6을 승인했다. 기존 테마를 유지하고 다음 3개를 초기 선택·후보 선택 단계에 추가했다. 미리보기와 편집 가능한 PPTX는 같은 DesignSystem을 사용한다.

원본 레모네이드 토큰을 그대로 덮어쓴 것이 아니라, 이번 대화에서 보여주고 승인받은 가독성 조정안이다. 미선택 BIT 청록·버건디·슬레이트 블루는 등록하지 않았다.

## 검증

텍스트·DOCX·PPTX·PDF 추출, 쪽 위치, 후반부 근거 검색, 중복 제거, 예산 제한, 키/원본 비전달, 축약 대화, 기존 덱 호환, 승인 테마 등록과 대비를 포함한 테스트 20개 및 타입 검사 통과. 브라우저에서 Markdown 첨부·추출·목록 표시와 새 색상 3개 표시를 확인했다. 실제 AI 분석 품질·과금은 검증하지 않았다.

최종 프로덕션 빌드도 통과했다. 새 /api/attachments 경로를 포함한다. 공개 배포는 하지 않았다.
