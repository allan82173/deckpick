# 장표 화면에서 직접 편집

전체 초안에서 텍스트를 누르면 해당 위치에 입력창이 열린다. 다른 곳을 누르거나 완료·Ctrl+Enter를 누르면 저장하고, Escape는 현재 입력을 취소한다. 텍스트와 도형·이미지 선택 시 장표 아래에 요소 도구가 나타난다. 텍스트는 글자색·크기·굵기, 도형은 색상, 모든 요소는 가로·세로 위치와 너비·높이를 바꿀 수 있다. 원래대로는 선택 요소의 편집만 되돌린다. 이미지 파일 교체는 기존 후보 비교 화면의 표지 사진 선택 기능을 이용한다. 자유 드래그·회전·개체 추가·삭제까지 제공하는 PowerPoint 전체 편집기를 구현한 것은 아니다.

수정 사항은 SlideSpec.canvasEdits에 원본 요소의 종류·위치·내용을 기준으로 저장한다. AI가 생성한 원본 data와 분리되며 공통 makeScene에서 적용하므로 실제 장표·왼쪽 미리보기·네이티브 PPTX 텍스트/도형에 동일하게 반영한다. 제목 수정은 목록과 장표 카드 제목에도 표시한다. 앞뒤 장 맥락과 추가 후보 생성에는 화면 수정 정보도 전달한다. 새 레이아웃으로 교체할 때 과거 구조의 편집값을 강제 재적용하지 않는다.

‘이 장 다른 후보 보기’는 오른쪽의 녹색 버튼으로 바꾸었다. 페이지 추가도 DeckPick 로고의 녹색으로 채워 강조했다. 전체 초안의 기존 ‘문구 직접 수정’ 버튼과 별도 입력 폼은 화면 직접 편집으로 대체하고, 후보 비교 화면의 상세 편집은 유지한다.

검증: 저장 스키마 왕복, 수정 텍스트·색상·위치의 실제 PPTX XML 반영, 다른 장 보존, 탐색 목차 변경 시 수정 보존, 잘못된 색상 거부와 캔버스 범위 제한을 포함한 56개 테스트와 TypeScript 검사를 통과했다. 유료 AI 호출 없이 검증한다.

프로덕션 빌드 통과. 별도 데모 브라우저에서 제목 직접 수정→새로고침 후 보존→글자 크기 28·도형 위치 수정→7장 PPTX 다운로드를 확인했다. 실제 PPTX의 네이티브 텍스트와 글자 크기 값에 변경 내용이 포함된다. 파일은 `web/output/canvas-edit-browser-validation.pptx`, 화면은 `web/output/screenshots/canvas-edit-and-buttons.png` 및 `canvas-inline-editor.png`다.
