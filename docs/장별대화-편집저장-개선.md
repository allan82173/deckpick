# 장별 대화와 편집 저장 개선

2026-10-30 중단 작업(편집 저장, 새 페이지 근거 파일, 버튼 중앙 정렬)을 이어 완료하고 장별 대화를 추가한다. 기존 키·모델을 그대로 사용하며 배포하지 않는다.

## 편집

기존 브라우저 textarea의 자체 resize는 화면 입력창만 늘렸고 장표 좌표에는 저장되지 않았다. 또 blur 시 텍스트 저장과 속성 변경, 완료 시 재저장이 이전 렌더 값으로 서로 덮어쓸 수 있었다. 텍스트·속성 변경을 최신 SlideSpec에 합치는 patchCanvasNode로 통일하고 완료는 편집 종료만 한다. 입력은 즉시 저장한다. 미리보기와 네이티브 PPTX는 같은 좌표와 편집값을 사용한다.

선택 요소 상단의 이동 손잡이와 오른쪽 아래의 크기 손잡이로 직접 드래그한다. 크기 손잡이는 화살표 키도 지원한다. 텍스트 입력창의 화면 글자 크기는 장표 축척에 맞춘다. Escape는 현재 편집 세션의 변경을 취소한다. 원래대로는 선택 요소만 초기화한다. 후보 전환 시 편집 컴포넌트를 새 후보에 맞춰 재시작한다. 자유 개체 생성·회전까지 구현한 것은 아니다.

한글은 공백 단위 단어를 우선 보존하며, 한 단어가 상자보다 길 때만 문자 단위로 나눈다. 표지 제목은 한 줄을 우선하되 16pt보다 작아져야 들어갈 만큼 길면 읽을 수 있는 여러 줄과 경고를 사용한다. 자동 제목 제안은 가급적 24자 이내로 요청하고 설명은 부제로 옮긴다.

## 파일과 추가 버튼

본문 ‘페이지 추가’ 영역의 너비를 오른쪽 후보 패널을 뺀 실제 큰 장표 너비와 일치시켜 중앙을 맞춘다. 모바일에서 후보가 아래로 내려갈 때에는 전체 본문 너비를 쓴다. 왼쪽 목록의 +는 그대로 같은 입력창을 연다.

새 페이지 입력창에서 문서·사진 최대 5개, 개당 10MB를 첨부·드롭할 수 있다. 로컬 추출 캐시와 기존 발췌 예산을 사용하며 파일을 통째로 프롬프트에 넣지 않는다. 파일 메타데이터는 해당 outline item에 보관해 페이지 삽입 시 함께 이동한다. 해당 장 생성·후보·대화에서 이 장 파일을 우선하고 덱 공통 파일을 합쳐 중복 제거 후 최대 5개를 읽는다. 다른 장으로 자동 확산하지 않는다. 생성 후 해당 장 대화창에서 근거 파일명을 확인할 수 있다.

## 장별 AI 대화

왼쪽 목록–가운데 큰 장표–오른쪽 후보 3개 구조는 유지하고 큰 장표 아래에 접을 수 있는 대화창을 둔다. 기록은 deck.chat.slides에 장별로 저장한다. 여러 창을 열거나 서로 다른 장의 요청을 진행할 수 있다.

각 요청에 현재 장의 실제 텍스트, 최근 대화 최대 8개, 전체 최대 30장의 최신 표시 내용 요약(장당 최대 1,400자)과 최근 사용자 요청 2개(각 400자)를 전달한다. 모델의 영구 기억이나 별도 학습이 아니라 요청 시점의 공유 스냅샷이다. 1번 장의 변경이 반영된 후 14번에서 요청하면 1번의 최신 내용이 함께 들어간다. 동시에 진행 중인 미완료 응답은 완료 후 다음 요청에서 공유된다. 긴 과거 대화 전체와 첨부 원문 전체가 항상 전달된다고 표현하지 않는다.

AI는 해당 장의 표시 텍스트를 정확히 지목한 before/after 변경안과 답변을 반환한다. 기존 구조·사진·도형 위치는 보존하고 해당 장에만 적용한다. 응답 전 사용자가 직접 내용을 바꿨으면 자동 덮어쓰지 않는다. 없는 텍스트를 바꾸려는 응답은 거부하고 원본을 유지한다. 현재 대화 편집은 텍스트 변경이며 AI가 구조·개체를 무제한 추가하는 기능은 아니다. 원본 후보·직접 수정·다른 장 기록은 유지한다.

## 검증

68개 테스트 통과. 연속 텍스트/너비/스타일 변경의 저장·PPTX 반영, 한글 단어 줄바꿈, 한 줄 표지, 장별 파일 보존·선택, 14번 요청에 1번의 실제 수정 내용과 최근 요청이 들어가는지를 확인한다. AI API는 모의 응답으로 검증하며 실제 유료 호출·추가 충전은 하지 않는다. 실제 AI 응답의 품질과 계정의 사용 가능 잔액은 이 검증으로 보장하지 않는다.

로컬 서버가 Request URL을 내부 주소로 바꾸면서 브라우저가 사용한 Host와 달라지는 문제가 있었다. 같은 출처인지는 Origin과 실제 Host 헤더로 비교하도록 정리했다. Host가 없는 테스트에서는 request.url을 사용하며 외부 Origin 거부 검사를 유지한다.

실제 데모 화면에서 텍스트 변경→너비·글자 크기 수정→완료→새로고침→후보 B/A 전환 후 제목 보존, 크기 손잡이 마우스 드래그, 장별 대화 기록, 장표와 추가 버튼의 중앙 차이 0.001px 미만을 확인했다. 파일 선택으로 예시 TXT 41자를 추출하고 해당 장 근거로 보관한 뒤 PPTX를 다운로드했다. 네이티브 텍스트는 수정 제목을 유지하고 드래그한 폭 8.85in·높이 2.87in을 반영한다. 실제 AI 대화는 모의 API 테스트로 1번→14번 공유와 대상 장만 변경하는 동작을 확인했다.

검증 산출물: `web/output/editor-shared-chat-validation.pptx`, 화면은 `web/output/screenshots/per-slide-chat-shared-context.png`, `editor-save-resize-fixed.png`, `insert-slide-reference-file.png`다. 새 유료 API 호출은 수행하지 않았다.
