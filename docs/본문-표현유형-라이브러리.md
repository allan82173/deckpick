# 본문 표현 유형 라이브러리 · 2026-10-29

## 사용자 요청과 적용 범위

참고 PPT와 최신 ICT PDF에서 관찰한 표현 문법을 실제 데이터 계약·미리보기·후보 생성·PPTX로 연결했다. 모델 가중치를 훈련한 것은 아니며 원본 자료의 기업·수치·문구를 새 프로젝트의 근거로 복제하지 않는다. 기존 저장 후보를 자동으로 덮어쓰지 않는다. 로컬 작업만 수행하며 배포하지 않는다.

추가한 독립 구조는 9종이다. 각각 컨설팅과 마케팅의 두 접두사로 등록해 새 layout ID는 18개다. 총 35개 ID이며, 표지·목차를 제외하고 라이브러리에서 고를 수 있는 본문은 컨설팅 18개, 마케팅 14개다. 표지의 기존 3안 선택 기능은 유지한다.

## 사용 흐름

1. 후보 선택·수정에서 표지 이외 장표를 고른다.
2. ‘전체 본문 유형 보기’를 펼친다. 6개 관계 유형으로 필터링하고 예시 미리보기를 본다. 모든 구성을 미리 AI로 생성하는 방식이 아니다.
3. 바꿀 후보 A/B/C를 정하고 ‘이 구성 사용’을 누른다. 현재 다른 후보에 있는 레이아웃은 중복 선택을 막는다.
4. AI 모드는 지정한 레이아웃으로 현재 장의 메시지·근거를 재구성하는 단일 후보 요청을 보낸다. 검증 실패 시 기존 최대 2회 수정 요청이 추가될 수 있다. 데모 모드는 합성·검토용 예시를 제공하며 첨부를 분석한 것처럼 표현하지 않는다.
5. 남은 두 후보와 다른 장의 선택·수정은 보존한다. 교체 대상이 직접 수정한 선택 후보라면 초기화 전에 확인한다. 실패해도 기존 후보를 유지하고 같은 레이아웃을 재시도할 수 있다.

자동 추천은 섹션 이름보다 내용에 명시된 고객 여정·정보 단절·데이터 연결·역할·추세 등의 관계 신호를 먼저 본다. 여전히 규칙 기반 분류이며 사용자 의도를 완벽하게 파악하는 모델형 라우터는 아니다. 후보는 한 번에 3개를 비교하고, 라이브러리는 그 밖의 선택지를 모두 보여 준다.

## 데이터와 편집

새 구조는 zod로 길이·개수·상대 위치·수치 범위를 검증한다. 실측 추세 후보는 확인된 웹 출처 또는 첨부 파일 위치를 노트에 남기도록 검증한다. 가설·제안·실측·합성 구분을 미리보기에 표시한다. 데모 차트 값은 합성 값이며 실제 성과로 쓰지 않는다.

직접 수정에서 글자뿐 아니라 좌표·수치·강조 체크·상태 선택도 편집할 수 있다. 포지셔닝 항목의 x/y는 0~1이며 단계 강조는 0부터 시작한다. 원인이나 위치를 자동으로 사실 판정하는 기능은 아니다.

추세는 현재 한 개 계열의 비음수 막대 시각화다. 여러 계열·음수·복합 차트·자동 통계 분석·PowerPoint 차트 데이터 시트는 범위 밖이다. 출력 막대와 축은 편집 가능한 도형·텍스트이며 네이티브 차트 개체가 아니다.

## 검증

- 타입 검사, 테스트 43개 통과. 새 18개 ID의 스키마·영역·샘플 문구 넘침, 양쪽 덱의 6개 유형 노출, 관계 우선 추천, 잘못된 유형 거절, 단일 후보 보존, 수치·출처 제한을 확인했다.
- 대체 제공자 응답을 사용해 API 경로가 라이브러리에서 고른 정확한 레이아웃을 한 개 반환하는지 확인했다. 실제 유료 API 호출·생성 품질은 이번에 검증하지 않았다.
- 전체 35개 레이아웃이 편집 가능한 텍스트·도형 및 출처 노트로 PPTX에 들어가는 기존 내보내기 테스트를 통과했다.
- 실제 브라우저의 데모에서 시스템 구조 필터·후보 C 지정·교체를 실행하고, A/B 카드 DOM이 그대로이며 C만 바뀐 것을 확인했다. 기존 API 모드는 검증 후 복원한다.
- 기존 AI 모드 복원과 전체 새 구조의 화면 검토를 마쳤고, 프로덕션 빌드도 통과했다. 로컬 개발 서버를 3100번에서 다시 실행했다. 배포·실제 유료 AI 요청은 수행하지 않았다.
