# 전체 초안 사이에 페이지 추가

전체 초안의 각 장 아래에서 ‘N번과 N+1번 사이에 페이지 추가’를 누른다. 마지막 장 뒤에도 추가할 수 있다. 키메시지·질문·메모 한 문장만 필수이며, 섹션 이름과 포함할 근거는 선택 사항이다. 먼저 한 장을 만든 후 ‘이 장 다른 후보 보기’의 AI 대화로 보완하는 흐름이다.

AI 모드에서는 앞뒤 장의 실제 선택·수정 내용과 연결된 출처, 덱 자료를 전달하여 새 장 하나만 생성한다. 데모 모드는 입력 문장에 준비된 예시를 붙이며 실제 자료 분석을 하지 않는다. 기존 후보·선택·수정·장별 대화·교체 회차는 삽입 위치에 맞춰 이동한다. 탐색 목차와 페이지 번호는 새 순서로 표시된다.

처음 장수 선택은 5~12장을 유지한다. 중간 추가로 최대 30장까지 늘릴 수 있으며 저장, 생성 요청, PPTX 출력이 늘어난 장수를 지원한다. 생성 실패 시 새 위치와 메시지는 저장하고 전체 초안의 누락 장 재시도로 복구한다. 기존 완성 장을 재생성하지 않는다.

검증: 53개 테스트 통과, TypeScript 검사 및 프로덕션 빌드 통과. 중간 삽입 시 기록 이동·보존, 앞뒤 실제 내용 전달, 13장 생성 요청과 PPTX 출력, 30장 제한을 검사했다. 별도 데모 브라우저에서 6장 사이에 한 장을 삽입하여 7장 표시 및 기존 6장 본문 보존을 확인했다. 실제 유료 API 생성 품질은 이번 검증에 포함하지 않았다.
