# 화면에서 박스 크기 조절 — 2026-10-30

한 번 클릭해 선택한 뒤 네 모서리와 네 변의 8개 손잡이를 끌어 너비·높이를 늘리거나 줄인다. 내부 또는 테두리로 이동하며, 두 번 클릭하거나 ‘문구 편집’을 눌러 글자를 입력한다. 글자 크기·굵기·색상은 기본 툴바에 유지하고, 위치·너비·높이 숫자는 ‘정밀 조절’ 안에 둔다.

표지의 한 줄 제목도 사용자가 너비를 바꾸면 새 너비에 맞춰 줄바꿈한다. 글자 크기는 자동 변경하지 않는다. 최신 슬라이드에 즉시 저장하며 완료는 선택만 해제한다. 드래그는 표시 비율에 맞춰 좌표를 환산하고 반대 변 고정·최소 크기·장표 경계를 지킨다. 회전과 그룹 선택은 지원하지 않는다.

검증: 71개 테스트, 타입 검사, 프로덕션 빌드 통과. 별도 데모에서 오른쪽 아래와 왼쪽 가운데 손잡이를 실제 마우스로 안쪽으로 끌어 488×158px 박스를 338×85px로 축소했다. 완료·새로고침 후 크기와 글자 크기 26 유지, 두 번 클릭한 문구 수정도 확인했다. 사용자 원본 덱 변경과 유료 AI 호출 없이 검증했다.
