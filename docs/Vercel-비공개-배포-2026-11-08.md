## 사용
본인의 접근 권한이 있는 Vercel 계정으로 대표 주소에 로그인한다. 클라우드 서버에는 로컬 OpenAI/Anthropic 키를 복사하지 않았으므로 AI 연결 설정에 자신의 API 키를 입력한다. 기존 브라우저 세션 저장 방식을 유지한다. localhost의 작업·첨부는 다른 origin의 클라우드 사이트에 자동 이전되지 않는다. 같은 입력을 다시 쓸 때 파일을 새로 첨부한다.

## 클라우드 대응
- private-storage.ts: 로컬은 기존 파일시스템, Vercel은 Private Blob. 첨부 추출본·이미지·첨부 근거 캐시·체크포인트·시도 리포트·완성 리포트를 지속 저장한다. 최신 원문 읽기는 useCache:false를 사용하며 비공개 저장소 URL을 일반 방문자에게 노출하지 않는다.
- 큰 첨부는 서명된 클라이언트 업로드로 Blob에 직접 보내고 서버가 제한된 업로드 경로·용량을 확인한 뒤 추출한다. 토큰 경로는 Vercel 로그인 보호와 동일 출처 검사를 거친다. PDF 30MB/기타 10MB 규칙은 유지한다.
- Vercel 조사 요청은 핵심 질문별로 분리하고 앞 질문의 근거·출처·라운드를 누적한다. 로컬 조사 방식은 유지한다. 클라우드 단계 예산은 generation-config.hosting.stageBudgetMs(270초), 함수 maxDuration은 300초다. 긴 과제는 중간 저장에서 재개해야 할 수 있다.
- 공개 데모 버튼·이전 이미지 미리보기는 비공개 모드에서 제외하고 새 작업은 AI 모드로 시작한다. 기존 예시 소스는 로컬 회귀 검증용으로 남기되 클라우드 예시 경로를 비활성화하고 데모 이미지 자산은 배포에서 제외했다.
- .vercelignore에서 .generation-runs, .attachments, output, .key-setup, .env 및 원본 예시 자산을 제외했다. 서버의 새 저장소 인증 값은 Vercel 환경변수에만 연결했고 저장소 코드에는 기록하지 않는다.
