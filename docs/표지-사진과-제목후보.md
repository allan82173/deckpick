# 표지 사진·제목 후보 개선 · 2026-10-29

## 문제와 변경

사용자 캡처에서 컨설팅 표지 3개는 같은 단색 배치와 제목을 사용하고 부제만 달랐다. 기존 참고자료 부족보다 렌더러와 후보 생성 규칙의 제약이었다.

- 같은 `c-cover` 계약에 선택적 `coverStyle`을 추가했다. 사진 반반형, 화이트 보고서형, 큰 제목형을 각각 후보 A/B/C로 제공한다. 새 layout ID나 전면 데이터 교체 없이 기존 덱을 유지한다.
- 스타일 없는 기존 저장 표지는 기존 단색형으로 열린다. ‘표지 디자인 3안 적용 · API 사용 없음’을 눌렀을 때에만 표지 후보를 교체하고 표지 선택을 해제한다. 다른 장의 후보·선택·수정은 유지한다. 직접 수정한 표지가 있으면 확인 후 그 부제·발표자를 기준으로 만든다.
- 데모 제목도 서로 다르게 제공한다. 실제 API는 부제만 다른 동일 제목을 거절하고 제한된 재시도 안에서 수정하도록 한다. 컨설팅 표지에서만 이 규칙을 적용한다.
- 사진은 오른쪽 6.7×7.5인치로 약 절반을 차지하고 중앙 기준으로 잘라 표시한다. 제목·부제·발표자는 왼쪽의 흰 영역에 둔다. 나머지 두 후보는 흰 보고서형, 큰 제목과 오른쪽 테마 색 면으로 구분한다.

## 사진

MGRV 주제에는 공식 홈페이지 https://mangrove.city/ 에 게시된 사진 https://static.mgrv.net/mangrove-city/main/main-background-7.webp 를 참고용 표지에 사용한다. 사람 뒷모습과 맹그로브 안내물을 보여 주는 실제 공간 사진이다. 다른 브랜드 프로젝트에는 자동 사용하지 않는다. 앱 자산은 긴 변 1,600px JPEG로 저장했다. 사진 출처는 표지와 PPTX 발표자 노트에 표시한다. 로컬 구현과 검증만 수행하며 배포하지 않는다.

선택한 장표 직접 수정에서 표지 구성을 바꾸거나 PNG·JPG·WebP를 업로드해 교체할 수 있다. 기존 채팅 첨부 사진도 명시적으로 선택할 수 있다. 채팅의 사진을 임의로 표지로 선택하지 않는다. 표지 전용 업로드는 AI 분석 목록에 자동 추가하지 않는다. 사진 파일이 없으면 사진 자리를 명확히 표시하며 실제 사진으로 가장하지 않는다.

## 구현과 검증 범위

미리보기와 PPTX가 같은 ImageNode 좌표를 사용한다. SVG는 중앙 crop, PPTX는 네이티브 그림의 cover crop을 사용하고 제목은 편집 가능한 텍스트로 유지한다. 사용자 사진은 비공개 첨부 경로에서 PNG로 읽어 PPTX에 포함한다. 외부 임의 URL을 가져오는 프록시는 만들지 않는다.

검증: 타입 검사와 테스트 37개 통과. 새 표지의 제목·배치 구분, 영역·넘침, 기존 데이터 호환, 네이티브 사진과 자르기·출처가 들어간 PPTX, 동일 제목 AI 응답 수정(대체 응답)을 확인했다. 앱 내 브라우저에서 localhost:3100 접속·새 적용 버튼과 전환을 확인했으며, MGRV 3안의 시각 검토도 완료했다. 유료 API 생성 품질과 사용자 PowerPoint 환경의 렌더링까지 검증한 뜻은 아니다.

참고 학습 자료 6종·299장은 기본 스타일 규칙을 구성하기에 충분하다. 추가로 유용한 것은 원하는 표지 2~3장의 구체적인 좋고 싫은 점, 프로젝트에 사용할 사진, 발표의 핵심 질문이다. 자료를 읽고 생성 규칙·레이아웃에 반영한 것이며 모델 가중치 파인튜닝을 수행한 것이 아니다.

## 브라우저 확인 문제

Windows 네이티브 Chrome 창 제어는 주소를 충분히 확신하지 못해 중단됐다. localhost 서버 장애로 확인된 것이 아니다. 앱 내 브라우저의 명시적 URL 탭으로 재접속해 정상 페이지와 변경 UI를 확인했다. Chrome 주소 인식 도구 자체를 고치거나 안전 확인을 우회한 것은 아니다. 사용자의 Chrome MGRV 덱을 직접 덮어쓰지 않았다.
