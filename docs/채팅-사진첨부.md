# 채팅 사진 첨부 · 2026-10-29

## 사용 방식

- 채팅 입력창에서 캡처한 사진을 Ctrl+V로 붙여넣는다.
- 사진을 AI 채팅 영역으로 끌어 넣거나, 입력창의 사진 버튼으로 선택한다.
- PNG·JPG·WebP를 지원한다. 문서와 사진을 합쳐 최대 5개, 개당 10MB다.
- 미리보기와 크기를 확인하고 내용을 입력해 전송한다. 사진만 전송해도 핵심 내용·발표 구성 제안을 요청할 수 있다. 전송된 대화에는 사진 썸네일이 남는다.
- 붙여넣기·업로드만으로 AI 분석을 시작하지 않는다. 데모는 실제 이미지 분석을 수행하지 않는다.

## 비용과 이미지 처리

로컬 서버에서 이미지 형식·최대 픽셀 수·단일 프레임을 확인하고 EXIF 방향을 보정한다. 긴 변 최대 1,600px의 WebP로 변환하며 EXIF 등 메타데이터를 제거한다. 원본 바이너리는 저장하지 않는다. 작은 글자·도표가 흐리면 필요한 부분만 잘라 다시 첨부한다.

‘저비용 · 큰 구성만’은 최대 512px로 축소하고 OpenAI에는 low detail을 요청한다. 글자·도표 읽기는 auto detail을 사용한다. 이미지 토큰은 문서 발췌의 약 2,400토큰 예산과 별도이며, 압축 파일 크기가 줄어든 만큼 과금 토큰이 비례해 줄어든다는 뜻은 아니다.

‘AI 분석에 포함’이 켜진 사진은 이후 대화·목차·후보 생성 요청에도 함께 전달된다. 필요가 없으면 체크를 끄거나 첨부를 해제한다. 해제는 덱의 연결만 제거하며 로컬 캐시는 남는다.

## 데이터 경로와 검증

브라우저에는 ID·파일명·크기·옵션만 저장한다. 사진은 Git·Vercel 제외인 `web/.attachments/`에 저장하며 미리보기 경로는 `/api/attachments/[id]`다. 서버에서만 이미지를 읽어 OpenAI Responses의 input_image 또는 Claude Messages의 image 블록으로 전달한다. 첨부 자료 안의 명령은 실행 지침으로 취급하지 않도록 안내한다.

테스트는 이미지 변환·메타데이터 제거, 위장 이미지 거절, 미리보기 경로와 교차 사이트 차단, 분석 제외·저비용 옵션, 제공자별 이미지 입력, 실제 채팅 경로에서 이미지 전달을 대체 응답으로 확인한다. 브라우저에서는 파일 선택과 Ctrl+V 붙여넣기, 썸네일 표시·첨부 해제를 확인했다. 유료 API 호출과 실제 이미지 해석 품질은 검증하지 않았다. 배포는 하지 않는다.

이 기능은 채팅의 참고 이미지 분석이다. 참고 사진을 최종 PPTX에 자동 삽입하는 기능은 포함하지 않는다. 공개 배포 전 인증·파일 소유권·영구 저장 설계가 필요하다.
