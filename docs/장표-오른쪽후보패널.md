# 장표 오른쪽 후보 패널

2026-10-30 요청: ‘이 장 다른 후보 보기’를 장표 오른쪽 여백의 맨 위에 배치하고, 아래에 후보 약 3개를 보여준다.

전체 초안의 각 장표 오른쪽에 고정 패널을 둔다. 버튼 아래에 A·B·C 세 자리를 표시하며, 현재 초안도 세 후보 중 하나다. 추가 후보는 버튼을 눌렀을 때만 기존 ensureAlternatives 흐름으로 두 개까지 채운다. 저장된 후보는 즉시 표시하고 다시 호출하지 않는다. 생성 전·도중·부분 실패에는 빈 후보 자리를 안내하고, 준비된 후보는 유지한다.

후보를 누르면 같은 화면의 큰 장표와 왼쪽 페이지 미리보기에 적용된다. 후보 전환 시 이전 후보의 직접 수정은 해당 후보에 보관해 되돌아왔을 때 복원한다. 다른 장표·대화는 건드리지 않는다. ‘AI 대화·후보 상세 수정’으로 기존 상세 화면을 열 수 있다. 좁은 화면에서는 장표 밑에 세 후보를 가로로 배치한다.

검증: 후보 A·B 각각의 수정 보존 및 다른 장표 불변을 포함한 57개 테스트, TypeScript 검사 통과. 유료 API 호출 없이 데모에서 화면을 확인한다.
